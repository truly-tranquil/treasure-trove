# Treasure Trove

A community-run program for self-paced courses and a free learning library for adult learners (18+).

[https://truly-tranquil.github.io/treasure-trove/](https://truly-tranquil.github.io/treasure-trove/)

## What's here

- **Student Success 101 (STU-101)** — a free, 4-week, self-paced course with 16 sessions across 4 modules, plus a capstone Personal Student Success Plan.
- **Learning Library** — 16 curated categories of free and low-cost books, courses, tutoring, open courseware, creative tools, and community resources.
- **Get Help** — crisis lines, therapy finders, and wellness tools (US-focused with international options).
- **What's Next** — vote on the next course to be built.
