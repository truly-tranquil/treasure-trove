## Handout 3-A: Time Audit Summary { #handout-3a }

*Session 1 (predict) and Session 4 (review) · about 5 minutes to predict, about 20 minutes to review, plus about 5 minutes a day of tracking*

A time audit shows the gap between where you think your time goes and where it really goes. You predict first, track honestly all week, then compare. The gap is the lesson, not a grade.

**Get a copy:** [Google Doc](https://docs.google.com/document/d/1pflotCLSeFuOlD4L7y_iNYY5M2BXESiWWr3Jo235010/copy) · [PDF](https://docs.google.com/document/d/1pflotCLSeFuOlD4L7y_iNYY5M2BXESiWWr3Jo235010/export?format=pdf) · [Word](https://docs.google.com/document/d/1pflotCLSeFuOlD4L7y_iNYY5M2BXESiWWr3Jo235010/export?format=docx)

### How to track

Each evening, fill in what you actually did, in blocks of about 30 minutes. Rough is fine. You can use the Iowa State Academic Success Center's [Time Audit worksheet (Word file)](https://asc.dso.iastate.edu/files/documents/2026-02/Time%20Audit.docx), a paper grid, or a notes app. No Word? Copy the layout onto paper: days across the top, hours down the side.

### What goes on it

Fill in the **My prediction** column at the start of the week, before you track. Fill in the rest in Session 4. The gap is your log minus your prediction.

A week has 168 hours. Make "Other" whatever is left over (meals, commuting, errands, downtime), so each column adds up to 168.

| Category | My prediction (hrs) | My log (hrs) | Gap | Surprise? |
|----------|---------------------|--------------|-----|-----------|
| Classes / scheduled learning |  |  |  |  |
| Study |  |  |  |  |
| Sleep |  |  |  |  |
| Work / caregiving / commitments |  |  |  |  |
| Screens (non-academic) |  |  |  |  |
| Other (meals, commuting, errands, downtime) |  |  |  |  |
| **Total** | 168 | 168 | 0 |  |

- **My three biggest time leaks:** 1. … 2. … 3. …
- **One thing that took longer than I expected:** …
- **One time block that was better than I expected (protect this):** …

**Sensitivity:** if your week is dominated by work, caregiving, or commuting, that is not a leak. It's a constraint, and your plan has to be built around it.

**Options:** a paper grid, a spreadsheet, a notes app, or a short voice memo each evening.

**Low-tech floor:** a sheet of paper with a line for each day and a few words per block.

??? example "Worked example"

    | Category | My prediction (hrs) | My log (hrs) | Gap | Surprise? |
    |----------|---------------------|--------------|-----|-----------|
    | Classes / scheduled learning | 12 | 12 | 0 | No |
    | Study | 10 | 6 | −4 | Yes. I study much less than I think. |
    | Sleep | 56 | 49 | −7 | Yes. I sleep about 7 hours, not 8. |
    | Work / caregiving / commitments | 20 | 24 | +4 | A little. Shifts ran over. |
    | Screens (non-academic) | 7 | 16 | +9 | Yes. Most of it is between tasks. |
    | Other (meals, commuting, errands, downtime) | 63 | 61 | −2 | No |
    | **Total** | 168 | 168 | 0 |  |

    **My three biggest time leaks:** 1. Checking my phone between study blocks. 2. Starting study sessions 30 minutes late. 3. Scrolling in bed.

    **One thing that took longer than I expected:** Errands on Saturday took 3 hours, not 1.

    **One time block that was better than I expected (protect this):** Tuesday mornings before work gave me 90 quiet minutes.

## Handout 3-B: My Weekly System { #handout-3b }

*Session 2 · about 40 minutes, plus 5 minutes to schedule your Sunday reset*

This handout holds three pieces of your weekly system: a plan for one real week, a triage note for when the week gets heavy, and a one-line decision about your tools. Plan in layers: fixed commitments first, then focus blocks for your hardest work, then a buffer. Whatever is left is flexible time.

**Get a copy:** [Google Doc](https://docs.google.com/document/d/1KU0ffEyhAXT3log5m74rS6DzzyEcAuFuy9Hl1cfQASM/copy) · [PDF](https://docs.google.com/document/d/1KU0ffEyhAXT3log5m74rS6DzzyEcAuFuy9Hl1cfQASM/export?format=pdf) · [Word](https://docs.google.com/document/d/1KU0ffEyhAXT3log5m74rS6DzzyEcAuFuy9Hl1cfQASM/export?format=docx)

### What goes on it

**Weekly plan skeleton.** Use one real upcoming week. Give each focus block a named task and a strategy from your [Strategy Toolkit card](../module-2/materials.md#handout-2d).

| | Mon | Tue | Wed | Thu | Fri | Sat | Sun |
|---|-----|-----|-----|-----|-----|-----|-----|
| Fixed commitments |  |  |  |  |  |  |  |
| Focus block (task + strategy) |  |  |  |  |  |  |  |
| Focus block (task + strategy) |  |  |  |  |  |  |  |
| Buffer |  |  |  |  |  |  |  |
| Sunday reset (15 min) |  |  |  |  |  |  |  |

**Priority-triage note (busy week).** Write every task for the week on the Eisenhower Matrix, then sort it here. Circle at least one "schedule" item and make sure it is in a focus block.

| Do now (urgent + important) | Schedule (important, not urgent) | Delegate or shorten (urgent, not important) | Drop or defer (neither) |
|-----------------------------|----------------------------------|---------------------------------------------|-------------------------|
|  |  |  |  |

**Tool decision (one line):** "I'll use ___ for my calendar or planner and ___ for notes because ___."

**The Sunday 15-minute reset.** Once a week, look at the week ahead, move or cancel what won't fit, and name your top three tasks. It grows out of the weekly reflection prompt in [Handout 1-E](../module-1/materials.md#handout-1e).

### Notes

- **Productivity tools.** Be skeptical of hype. A tool is useful if you will open it daily. Paper planners are a fully valid choice.
- **Focus-time methods.** Short timed work intervals (for example, 25 minutes on, 5 off) help some people start. Use them if they work for you, and drop them if they don't.

**Options:** a digital calendar, a paper planner, a wall calendar, or sticky notes on a single sheet.

??? example "Worked example"

    | | Mon | Tue | Wed | Thu | Fri | Sat | Sun |
    |---|-----|-----|-----|-----|-----|-----|-----|
    | Fixed commitments | Class 9–12, work 5–9 | Work 8–4 | Class 9–12, work 5–9 | Work 8–4 | Class 9–12 | Family day (from noon) | Free |
    | Focus block (task + strategy) | 12:30–1:30: Biology, blank-page retrieval | 4:30–5:30: Stats problem set, practice questions | 12:30–1:30: Biology, Day 3 retrieval | 4:30–5:30: Stats, interleave with Biology | 1–2: Psychology reading, SQ3R | | |
    | Focus block (task + strategy) | | | 4–4:30 (before work): Flashcards, 20 minutes | | | 9–10: Paper outline | |
    | Buffer | 2–4 p.m. | Evening | 2–3:30 p.m. | Evening | 2–5 p.m. | Evening | 2–4 p.m. |
    | Sunday reset (15 min) | | | | | | | 7 p.m. |

    **Triage note:**

    | Do now | Schedule | Delegate or shorten | Drop or defer |
    |--------|----------|---------------------|---------------|
    | Stats problem set (due Friday) | Paper outline; Day 3 Biology retrieval | Group chat logistics (ask someone to summarize) | Reorganizing my notes app |

    **Tool decision:** "I'll use a paper planner for my calendar and my phone's notes app for notes because I look at the planner every morning and I always have my phone."

## Handout 3-C: Break This Down { #handout-3c }

*Session 3 · about 25 minutes*

Big tasks feel scary because they look like one giant step. This handout turns one real task into a sequence of small, dated steps, names the first physical action, and gives you an if–then plan for the step you're most likely to avoid. Pick a real assignment or task, not a made-up one.

**Get a copy:** [Google Doc](https://docs.google.com/document/d/144u-XsI4CIGFFSlNidPmIZTZyO-QZDMh9TrH6N_o1ps/copy) · [PDF](https://docs.google.com/document/d/144u-XsI4CIGFFSlNidPmIZTZyO-QZDMh9TrH6N_o1ps/export?format=pdf) · [Word](https://docs.google.com/document/d/144u-XsI4CIGFFSlNidPmIZTZyO-QZDMh9TrH6N_o1ps/export?format=docx)

### What goes on it

**Task and deadline:** …

| # | Step | Checkpoint date | Done signal |
|---|------|-----------------|-------------|
| 1 |  |  |  |
| 2 |  |  |  |
| 3 |  |  |  |
| 4 |  |  |  |
| 5 |  |  |  |

Add rows if the task needs more steps. Add a checkpoint date and a visible "done" signal to at least two steps.

- **My next physical action:** …
- **If–then start plan:** "If it's ___ (time or place), then I will ___."
- **The feeling I expect, and what I'll tell myself:** …

### Notes

- **Be kind.** If you start late, restart. The next moment is a new chance to use the plan.
- **When it's more than procrastination.** If you're stuck on many tasks for weeks, or avoidance comes with persistent low mood, anxiety, or trouble focusing, talk with a counselor, doctor, or disability support office. [Module 4](../module-4/index.md) covers how to find those supports, and the [Get Help](../../../get-help.md) page lists places to start.

**Options:** written, a spreadsheet, or index cards in a row.

??? example "Worked example"

    **Task and deadline:** 5-page psychology paper, due Friday the 20th.

    | # | Step | Checkpoint date | Done signal |
    |---|------|-----------------|-------------|
    | 1 | Pick a topic and write one question | Mon 9th | The question is typed at the top of a blank document |
    | 2 | Find 4 sources | Wed 11th | Four links saved in one list |
    | 3 | Write a one-page outline | Thu 12th | Outline saved, with a topic sentence for each section |
    | 4 | Write a rough draft | Mon 16th | Five rough pages, even if they're messy |
    | 5 | Revise, read aloud once, and submit | Thu 19th | Submitted, with a day to spare |

    **My next physical action:** Open a blank document and type my question.

    **If–then start plan:** "If it's Monday at 7 p.m. at the kitchen table, then I will open a blank document and write one sentence."

    **The feeling I expect, and what I'll tell myself:** "I'll feel anxious about picking the wrong topic. I'll tell myself it's only a first draft of a question, and I can change it."

## Handout 3-D: Prep Plan { #handout-3d }

*Session 4 · about 35 minutes*

Work backward from the date. Put the exam or deadline at the bottom of your calendar, then place three spaced sessions and one practice test (or a draft review for an assignment) ahead of it. Each session names its topics, a retrieval method, and an if–then start.

**Get a copy:** [Google Doc](https://docs.google.com/document/d/1iUvDZTe8ODcS-NpfobmDRKBdZ_eK9EkaiB07gQGkzQg/copy) · [PDF](https://docs.google.com/document/d/1iUvDZTe8ODcS-NpfobmDRKBdZ_eK9EkaiB07gQGkzQg/export?format=pdf) · [Word](https://docs.google.com/document/d/1iUvDZTe8ODcS-NpfobmDRKBdZ_eK9EkaiB07gQGkzQg/export?format=docx)

### What goes on it

**Exam or assignment:** … **Date:** … **What it covers:** …

| Session | Date and time | Topics | Retrieval method | If–then start |
|---------|---------------|--------|------------------|---------------|
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |
| Practice test (or draft review) |  |  |  |  |

**Backup time if a session gets bumped:** …

**After-action review prompts (after the exam or submission):**

- What did I miss, and why?
- Which prep session helped most?
- What will I do differently next time?

### Notes

- **If the date is weeks away,** use the Day 1 / 3 / 7 pattern first, then lengthen the gaps. See [Handout 2-B](../module-2/materials.md#handout-2b).
- **If you have no upcoming exam,** use an assignment, a certification test, or a skill goal from your [SMART goals sheet](../module-1/materials.md#handout-1d).

**Options:** a paper calendar, a spreadsheet, or index cards for each session.

??? example "Worked example"

    **Exam:** Statistics midterm. **Date:** Friday the 20th. **What it covers:** chapters 4–6.

    | Session | Date and time | Topics | Retrieval method | If–then start |
    |---------|---------------|--------|------------------|---------------|
    | 1 | Tue 10th, 7 p.m. | Chapter 4 | Blank page, then check the chapter | If it's Tuesday after dinner, then I'll clear the table and set a 5-minute timer |
    | 2 | Fri 13th, 4 p.m. | Chapter 5, plus a quick retrieval of chapter 4 | Practice questions | If it's Friday after class, then I'll open the practice questions before checking my phone |
    | 3 | Mon 16th, 7 p.m. | Chapter 6, mixed with chapters 4 and 5 | Flashcards, then mixed problems | If it's Monday at 7, then I'll shuffle the flashcards first |
    | Practice test | Wed 18th, 6 p.m. | Chapters 4–6 | Timed, closed-book practice exam | If it's Wednesday at 6, then I'll put my phone in another room and start the timer |

    **Backup time if a session gets bumped:** Thursday the 19th, 7 p.m.

    **After-action review prompts:** What did I miss, and why? Which prep session helped most? What will I do differently next time?
