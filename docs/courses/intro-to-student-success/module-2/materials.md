## Handout 2-A: Technique Autopsy { #handout-2a }

*Session 1 · about 15 minutes*

An autopsy looks at what already happened. List the study techniques you actually used in your last real study session (not the ones you wish you'd used), then decide whether each was passive or active and how the research rates it. This is a working document, not a test.

**Get a copy:** [Google Doc](https://docs.google.com/document/d/1jW7eMwztipODQXw6r2mUcGTRhRay8E9qaINDYEFwvvg/copy) · [PDF](https://docs.google.com/document/d/1jW7eMwztipODQXw6r2mUcGTRhRay8E9qaINDYEFwvvg/export?format=pdf) · [Word](https://docs.google.com/document/d/1jW7eMwztipODQXw6r2mUcGTRhRay8E9qaINDYEFwvvg/export?format=docx)

### What goes on it

| Technique I used | Passive or active? | Dunlosky rating | One way to make it more active |
|------------------|--------------------|-----------------|--------------------------------|
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

Add rows if you used more techniques. A **passive** technique takes information in (reading, listening, copying). An **active** technique makes you produce something (recall, explain, solve, quiz yourself).

**Dunlosky rating key** (from the review you read in Session 1):

- **High:** practice testing, distributed practice
- **Moderate:** elaborative interrogation, self-explanation, interleaved practice
- **Low:** summarization, highlighting, keyword mnemonic, imagery for text, re-reading
- **Not rated:** a technique the review didn't rate. Write "Not rated," and judge it by whether it's passive or active.

**Options:** fill it in as a table, talk it through as a voice memo, or sketch it as two columns (passive on the left, active on the right).

??? example "Worked example"

    | Technique I used | Passive or active? | Dunlosky rating | One way to make it more active |
    |------------------|--------------------|-----------------|--------------------------------|
    | Re-reading the chapter | Passive | Low | After each section, close the book and write what I remember |
    | Highlighting key sentences | Passive | Low | Replace highlights with a margin question for each section, then answer it from memory |

## Handout 2-B: Spaced Practice Schedule { #handout-2b }

*Session 2 · about 10 minutes, plus a 2-sentence retrieval reflection*

Take the same study time and spread it across days. Work backward from your exam or deadline date, and retrieve (don't re-read) each time.

**Get a copy:** [Google Doc](https://docs.google.com/document/d/1Jwk2-dxdLz8LBHbJwESJfc34hqD_kT4ainKezegjtZs/copy) · [PDF](https://docs.google.com/document/d/1Jwk2-dxdLz8LBHbJwESJfc34hqD_kT4ainKezegjtZs/export?format=pdf) · [Word](https://docs.google.com/document/d/1Jwk2-dxdLz8LBHbJwESJfc34hqD_kT4ainKezegjtZs/export?format=docx)

### What goes on it

**Subject:** … **Exam or deadline date:** …

| Day / date | What I will retrieve | How (blank page, flashcards, practice questions) | Done? |
|------------|----------------------|--------------------------------------------------|-------|
| Day 1 |  |  |  |
| Day 3 |  |  |  |
| Day 7 |  |  |  |
| Before the exam |  |  |  |

- **Interleaved block:** mark one study block that mixes two topics or problem types.
- **Retrieval reflection (2 sentences):** What did the blank-page drill reveal?

**It will feel harder.** If your drill went badly, that is useful information, not failure. Re-studying would have felt better and taught you less.

**Options:** written, voice memo (say it aloud, then check), or flashcards on paper.

??? example "Worked example"

    **Subject:** Biology, cell respiration unit. **Exam date:** Friday the 20th.

    | Day / date | What I will retrieve | How | Done? |
    |------------|----------------------|-----|-------|
    | Day 1 (Mon 9th) | Glycolysis steps and where they happen | Blank page, 5 minutes | Not yet |
    | Day 3 (Wed 11th) | Glycolysis plus the Krebs cycle (interleaved block: alternate with last week's photosynthesis notes) | Practice questions from the textbook | Not yet |
    | Day 7 (Sun 15th) | All of cell respiration, then compare it with photosynthesis | Flashcards, then a blank page | Not yet |
    | Before the exam (Thu 19th) | Everything I missed on Day 7 | Practice questions | Not yet |

    **Retrieval reflection:** "I remembered the names of the steps but not where they happen. I'll focus on locations next time."

## Handout 2-C: Reading Log { #handout-2c }

*Session 4 · about 10 minutes, on top of the reading itself*

Use this log while you run Survey–Question–Read–Recite–Review on a real passage of 3–5 pages.

**Get a copy:** [Google Doc](https://docs.google.com/document/d/13jPY0KwGQUq0QvXuDv6ZhJ6RcO7SJPIpxRZZZ4aXPHY/copy) · [PDF](https://docs.google.com/document/d/13jPY0KwGQUq0QvXuDv6ZhJ6RcO7SJPIpxRZZZ4aXPHY/export?format=pdf) · [Word](https://docs.google.com/document/d/13jPY0KwGQUq0QvXuDv6ZhJ6RcO7SJPIpxRZZZ4aXPHY/export?format=docx)

### What goes on it

| Step | What I did |
|------|------------|
| **Survey** (what do I expect this to be about?) |  |
| **Question** (my 3–5 questions) |  |
| **Read and Recite** (my own-words answers) |  |
| **Review** (what I will check again, and when) |  |
| **Own-words check** (one thing I understood better than before) |  |

**Reading log (one paragraph):** describe how the routine went and what you will change next time.

**Options:** a typed table, a handwritten page, or a voice memo that walks through the five steps.

??? example "Worked example"

    | Step | What I did |
    |------|------------|
    | **Survey** | Headings were "Memory," "Encoding," and "Retrieval." I expect it to explain how memory works. |
    | **Question** | How does memory get stored? Why do I forget things? What helps me remember? |
    | **Read and Recite** | Memory is stored in stages, and forgetting often happens when I never retrieved the idea. Practicing recall helps most. |
    | **Review** | Reread my margin questions on Day 3 and answer them from memory. |
    | **Own-words check** | I finally understand why re-reading didn't work: I never tested myself. |

    **Reading log:** "Turning headings into questions kept me focused. Reciting after each section was hard, and I'd rather do it every two paragraphs next time."

## Handout 2-D: Strategy Toolkit Card { #handout-2d }

*End-of-week wrap-up · about 15 minutes*

This card is your personal toolkit for the rest of the course. Choose three strategies from this week, tie each one to a challenge you named in [Handout 1-A](../module-1/materials.md#handout-1a), and decide exactly when you'll use it. Specific beats ambitious: "after each lecture, for 10 minutes" is better than "I'll use retrieval practice."

### What goes on it

| Strategy | Challenge it targets (from Handout 1-A) | Specific use-case | When and how often | First use (date) |
|----------|------------------------------------------|-------------------|--------------------|------------------|
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |
| **One thing I'm dropping or doing less** |  |  |  |  |

This card and your [Handout 2-B](#handout-2b) schedule are the two things you'll make as your Week 2 pieces for the [capstone](../capstone.md).

**Options:** a typed table, an index card per strategy, or a voice memo for each row.

??? example "Worked example"

    | Strategy | Challenge it targets | Specific use-case | When and how often | First use (date) |
